# goltocraft
Site officiel de GoltoCraft

## Pages
- `index.html` — Accueil
- `reglement.html` — Règlement
- `credits.html` — Crédits
- `telechargement.html` — Téléchargement du launcher

Pour activer le téléchargement, ouvre `telechargement.html` et renseigne `LAUNCHER_URL` avec le lien direct vers `Goltocraft-Launcher-Setup.exe`.

Conserve également ton dossier `images/` existant sur GitHub pour le logo et l'arrière-plan.
